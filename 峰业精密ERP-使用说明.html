三、功能模块

3.1 工作台

📋 我的待办

当前角色待审批/处理的任务

✅ 我的已办

历史已处理业务单据

🔄 流程实例

各业务流程执行状态

📊 数据统计

业务概览与关键指标

3.2 销售管理

新建订单：工作台 → 发起流程 → 核心生产流 → 填写客户/产品/金额

调价申请：工作台 → 调价申请 → 新建申请 → 选订单 → 输入新金额 → 提交

⚠️ 仅允许调整已生效订单，需填写调价原因

3.3 库存与来货

来货登记：仓管登录 → 审批中心 → 处理来货登记任务

来货登记完成后自动创建销售订单并进入核心生产流

3.4 生产管理

生产下达：运营核对 → 厂长下达生产 → 车间执行 → 完工确认

车间进度：查看进行中工单/待下达/异常返工

3.5 费用与采购

费用报销：提交 → 部门主管初审 → 财务审核 → 总经理终审

金额超5000元需总经理审批

采购请求：部门主管审批 → 财务审核 → 总经理审批

3.6 AI分析

自然语言查询业务数据，生成分析报告

示例："本月销售趋势如何？" / "哪些客户欠款最多？"

3.7 系统管理（仅管理员）

👤 用户管理
🔐 角色权限
⚙️ 流程配置
📖 字典管理

四、核心工作流

4.1 核心生产流（11节点）

采购申请 → 财务审核 → 总经理审批 → 仓管来货登记 → 运营核对 → 财务入账 → 生产下达 → 车间生产 → 完工确认 → 质检确认 → 运营归档

4.2 调价申请

销售经理审批 → 总经理审批

4.3 来货登记

仓管登记 → 运营核对 → 财务入账 → 归档

4.4 费用报销

部门主管初审 → 财务审核 → 总经理终审

六、常见问题

Q: 页面黑屏/空白？

A: 按 Ctrl+F5 强制刷新浏览器缓存

Q: 看不到菜单？

A: 当前账号角色无权限，联系管理员分配

Q: 调价提交失败？

A: 确认订单状态为"已生效"，且当前为销售角色

Q: 时间显示不对？

A: 系统统一使用北京时间(UTC+8)，刷新即可

Q: 如何建新账号？

A: 管理员 → 系统管理 → 用户管理 → 新增
